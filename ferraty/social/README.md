# Obrázek pro sociální sítě

`moje-hory-social-4x5.png` — statický shareable obrázek (1080×1350 px, formát 4:5 pro
Instagram/Facebook feed) se souhrnnými statistikami, ve stejné tmavé/teal grafice jako
widget pro web (`../widget/`).

`moje-hory-social-4x5.html` je zdrojová šablona (čísla propsaná staticky, stejně jako
u widgetu) — otevři si ji v prohlížeči, nebo požádej o přegenerování PNG, až se čísla
zase posunou.
